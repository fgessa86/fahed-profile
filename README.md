# Fahed Al Essa — Profile

Mobile-first, swipeable single-page profile site. Plain HTML/CSS/JS, no build step.

- `index.html` — the 5 frames
- `styles.css` — dark navy theme, Playfair Display + Inter
- `app.js` — swipe/tap navigation, progress bar
- `assets/` — headshot photo + CV PDF

## Local preview

```
python3 -m http.server 8080
```

## Deploy

Static site, zero config. Deploys as-is to Vercel (or any static host).
